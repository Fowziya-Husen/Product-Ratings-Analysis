# Product Ratings Analysis

An exploratory data analysis and business intelligence project focused on electronics product ratings and customer review trends using Python and Power BI.

## Overview

This project analyzes electronics product review data to understand rating patterns, compare brands and product categories, and examine review activity over time. Python libraries are used for data preparation, analysis, and visualization, while Power BI presents the findings through an interactive dashboard.

## Project Goals

- Explore and analyze electronics product ratings.
- Identify brands and categories with the highest review volumes.
- Understand the distribution of customer ratings.
- Analyze yearly review trends.
- Present key findings through interactive data visualizations.

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Power BI

## Analysis Performed

- **Data Inspection:** Examined dataset structure, data types, and missing values.
- **Data Preparation:** Used Pandas and NumPy for data manipulation and preprocessing.
- **Rating Analysis:** Explored the distribution of product ratings.
- **Brand Comparison:** Compared brands based on review counts.
- **Category Analysis:** Examined review activity across product categories.
- **Time-Based Analysis:** Visualized review trends by year.
- **Dashboard Development:** Created Power BI visuals and KPI cards to present key metrics.

## Dashboard Highlights

The Power BI dashboard includes:

- Total Reviews
- Average Product Rating
- Review Counts by Brand
- Review Counts by Category
- Rating Distribution
- Yearly Review Trends
- Interactive filters for exploring the data

## Key Benefits

- Provides a clear overview of customer review activity.
- Makes it easier to compare review volumes across brands and categories.
- Helps identify patterns in product ratings.
- Demonstrates practical skills in data analysis, visualization, and business intelligence.
